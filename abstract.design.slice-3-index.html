The demo path

  1. As Abstract, create a vacancy for Acme Logistics with three positions and publish it.
  2. Open the client portal and see it with its charge rate.
  3. As Abstract, fill position 1 from the pool and position 2 by a manual fill.
  4. See both bookings in the client portal.
  5. Extend one booking. Cancel the other with a reason.
  6. Cancel the vacancy.

IDs refer to the slice 3 design brief: A = no design before, C = correction to an existing export. P1 = the demo path.
